# Daily Food Stipend Tracker 🍲

A responsive, colourful web application designed to track a daily KES 350 food stipend for a relative, complete with M-Pesa transaction note parsing and professional PDF export capabilities.

## Features
- **Interactive Calendar/List View:** Visual tracking for every day of the month with status indicators.
- **M-Pesa Note Integration:** Easily paste raw M-Pesa confirmation messages for any day; the app automatically extracts details like transaction codes and timestamps.
- **Aesthetic PDF Export:** Generates a structured, corporate-style ledger report optimized for print/PDF without relying on sloppy browser dumps.
- **Persistent Storage:** Saves your daily records locally in your browser so data isn't lost on refresh.

## Usage
Simply open the live GitHub Pages link on your mobile or desktop browser, log your daily transfers, paste your M-Pesa notes, and tap **"Generate Monthly Statement (PDF)"** when needed.
